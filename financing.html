融资余额变化与融资买入额

红柱为融资余额增加，绿柱为减少；折线为沪深融资买入额。

数据与口径：沪市、深市融资余额及融资买入额由 AKShare 通过金十数据中心公开历史汇总接口获取（该接口整理交易所公开数据），仅显示两市均有记录的日期。流通市值使用上交所每日股票情况中的主板、科创板“流通市值”和深交所每日证券类别汇总中的 A 股流通市值，合计后计算“融资余额 / A股流通市值 (%)”；B股、基金及其他证券不纳入。该比率仅显示有交易所历史市值记录的日期，早期日期会随自动回填逐步补齐。融资余额为融资负债余额；不等同于“融资融券余额”（后者还包含融券余额）。融资偿还额没有在历史汇总接口中稳定提供，因此图中“余额变化估算”=当日沪深合计融资余额−前一交易日合计融资余额，可能受权益调整等因素影响，不能当作精确的融资净买入。指数使用沪深300日收盘价，展示为起点=100的归一化走势。数据每日由 GitHub Actions 更新，非实时行情。
